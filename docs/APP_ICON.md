# elysium-browser anime app icon

ไอคอนรุ่น 1.3.11 สร้างใหม่จาก `assets/anime/avatar-cherry.webp` เพื่อคงคาแรกเตอร์ elysium-browser เดิม แล้วแปลงเป็นไฟล์ Windows หลายขนาดด้วย `npm run assets:icon`

Prompt ที่ใช้:

> Create a polished square Windows desktop application icon featuring a close-up head-and-shoulders portrait of the same cheerful blue-haired, blue-eyed elysium-browser heroine. Use a deep navy rounded-square tile, subtle cobalt/electric-cyan halo, and tiny sparkle accents. Keep the face centered, hair silhouette clear, and generous safe margins so it reads at 16–256 px. Premium crisp anime key art, high-contrast shapes, soft cel shading. No text, letters, wordmark, cherry fruit, watermark, or busy scenery.

ไฟล์ที่ได้:

- `assets/elysium-anime-icon-source.png` — ภาพต้นฉบับจาก ImageGen
- `assets/elysium-anime-icon.png` — master 1024×1024 พร้อมมุมโปร่งใสจริง
- `assets/elysium.png` — favicon 128×128
- `assets/elysium.ico` — Windows ICO ขนาด 16, 24, 32, 48, 64, 128 และ 256 พิกเซล
