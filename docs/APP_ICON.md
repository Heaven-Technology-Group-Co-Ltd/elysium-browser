# elysium-browser app icon

ไอคอนรุ่น 1.4.0 เปลี่ยนจากภาพอนิเมะเป็นตรา elysium-browser: ตัวอักษร E สีทองพาดผ่านดาว บนพื้นหลังกรมท่าพร้อมปราสาทเหนือเมฆ มีคำว่า ELYSIUM BROWSER ใต้ตรา ไฟล์ต้นฉบับ `assets/elysium-icon-source.png` (1254×1254) แล้วแปลงเป็นไฟล์ Windows หลายขนาดด้วย `npm run assets:icon` (ครอปขอบ, มาสก์มุมมนโปร่งใส, master 1024×1024)

ไฟล์ที่ได้:

- `assets/elysium-icon-source.png` — ภาพต้นฉบับ
- `assets/elysium-anime-icon.png` — master 1024×1024 พร้อมมุมโปร่งใสจริง (ชื่อไฟล์คงเดิมเพื่อไม่กระทบสคริปต์)
- `assets/elysium.png` — favicon 128×128
- `assets/elysium.ico` — Windows ICO ขนาด 16, 24, 32, 48, 64, 128 และ 256 พิกเซล
